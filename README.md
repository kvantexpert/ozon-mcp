## Рабочий принцип

Перед созданием следующей цифровой карточки:

1. Определить категорию и `type_id`.
2. Получить актуальный список характеристик через `ozon_category_attributes`.
3. Отделить обязательные поля от необязательных.
4. Для словарных характеристик искать реальные значения через `ozon_search_attributes_dictionary`.
5. Не придумывать значения лицензии: территория, срок, количество устройств и т.п.
6. Записывать характеристики через `ozon_update_characteristics`.
7. После записи обязательно читать карточку обратно и проверять фактические значения.
8. Отдельно проверить фотографии и статус доступности товара.

Такой порядок позволяет использовать этот товар как эталон для последующих карточек цифрового ПО на Ozon.
