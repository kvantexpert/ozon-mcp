# План массовой загрузки каталога 1С в Ozon

## Цель

Загрузить каталог товаров из GOODS.JSON в каталог Ozon.

Источник: GOODS.JSON — 31 982 предложения.

Важно: GOODS.JSON не изменять.

## Текущий статус

Массовая загрузка в Ozon пока НЕ запускалась.

Текущая задача — подготовить корректный payload для Ozon и сначала проверить одну тестовую карточку.

## Рабочая схема

GOODS.JSON → подготовка данных → категория Ozon + type_id → обязательные характеристики → тестовая карточка → ozon_product_import → партии до 100 товаров → весь каталог.

## Ограничение импорта

Ozon operation ozon_product_import использует POST /v3/product/import.

Максимум 100 товаров за запрос.

Импорт асинхронный, возвращается task_id.

Для 31 982 товаров потребуется примерно 320 партий.

## Что уже установлено

В аккаунте Ozon есть эталонная карточка:

- product_id: 6417979753
- offer_id: 4601546116680
- sku: 5865629857
- название: 1С:Бухгалтерия 8 ПРОФ. Электронная поставка
- description_category_id: 200001489 — Цифровые товары
- type_id: 971075562 — Код активации офисного приложения

Для этого type_id обязательный атрибут:

- 8229 — Тип

Фактические атрибуты эталонной карточки уже получены через ozon_product_attributes.

## Что делать дальше

1. Не загружать весь каталог.
2. Получить точный контракт ozon_product_import.
3. Сформировать одну тестовую карточку из GOODS.JSON.
4. Проверить payload.
5. Отправить одну карточку через ozon_product_import.
6. Проверить task_id и результат через ozon_product_import_info.
7. Только после успешного теста сформировать партии максимум по 100 товаров.
8. Последовательно загрузить весь каталог с контролем результатов.

## Важные правила

GOODS.JSON не изменять.

Не выдумывать изображения, характеристики или другие данные, которых нет в источнике.

Не считать импорт выполненным, пока Ozon не подтвердил результат.

ozon_search_attributes_dictionary — READ.

ozon_attributes_dictionary каталог MCP помечает как WRITE. Не использовать confirm_write=true без отдельной необходимости.

Для атрибута Тип (8229) поиск dictionary через ozon_search_attributes_dictionary возвращал пустой result. Не угадывать dictionary_value_id.
