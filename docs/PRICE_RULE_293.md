# Правило формирования цены для Ozon

Для 293 товаров из групп 00000002 и 00000003:

1. Если есть цена типа 00001 ("Цена рекомендованная") — использовать её.
2. Если 00001 отсутствует, использовать 00003 ("Цена для пост.партнеров").
3. Если отсутствуют 00001 и 00003, использовать 00004 ("Цена для дистрибьюторов").

Результат проверки:
- 244 товара имеют 00001;
- 38 товаров имеют 00003+00004;
- 6 товаров имеют 00002+00003+00004;
- 5 товаров имеют только 00004.

Таким образом, все 293 позиции имеют определяемую цену по правилу 00001 -> 00003 -> 00004.

Исходный GOODS.JSON не изменяется.
